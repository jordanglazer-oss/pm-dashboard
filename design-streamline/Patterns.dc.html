Density rules
Fewer boxes, fewer clicks
Five rules that account for most of the visual noise. They change containers and defaults only — no data, no calculation, no route is affected.
01 A card per concern, not a card per number
The stock page nests thirteen bordered tiles inside two bordered cards. Hairline dividers separate the same numbers with a quarter of the ink.

03 Show by default; collapse only reference
Thirty-four collapsible panels are persisted in pm:ui-prefs today. Sort them once: daily reading is always open, reference is a text link at the foot of the page that expands in place.

04 No card around a control you already have in the nav
The landing page devotes half a row to an "Add a Holding" card and half to a "Market Regime" card. The nav's + Add already opens the same form, and the regime already reads in the cockpit band directly above. Both cards come out; the one control they carried — the scoring-posture override — moves inline into the cockpit.
